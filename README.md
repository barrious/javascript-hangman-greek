Λογισμική Κρεμάλα (Greek Programming Hangman)
A browser-based Hangman game built with vanilla JavaScript, HTML, and CSS. 
The twist: all words are Greek programming terminology — making it both a fun game and a study tool for CS students.


Features
- Full Greek alphabet keyboard (on-screen buttons)
- Physical keyboard support — no mouse needed
- Sound effects (rope ambiance + error sound)
- Dynamic hangman illustration that updates with each mistake
- 30 programming terms in Greek
- New game/reset button
- Responsive design


How to Play
A random Greek programming word is selected at the start. Click a letter (or press it on your keyboard) to guess
You have 5 mistakes before the game ends. Try to guess the word before the hangman is complete!


Word List
All 30 words come from object-oriented programming and computer science vocabulary in Greek.

Built With
HTML5, CSS3, Vanilla JavaScript (DOM Manipulation, Events, Audio API)
